La realización de este proyecto se fundamenta en la necesidad de aplicar de manera práctica los conocimientos adquiridos sobre programación, electrónica y sistemas embebidos. Su desarrollo permitirá comprender cómo interactúan el software y el hardware dentro de un dispositivo electrónico
